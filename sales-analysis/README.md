# Sales Data Analysis

## Project Overview
This project analyzes sales data using SQL to identify revenue trends, top products, customer behavior, and business insights.

## Tools Used
- SQL
- MySQL

## Skills Demonstrated
- SELECT
- JOIN
- GROUP BY
- HAVING
- Window Functions
- CTEs

## Business Questions
1. What are the top-selling products?
2. Which month generated the highest revenue?
3. Which customers spent the most?
4. Which region performs best?
